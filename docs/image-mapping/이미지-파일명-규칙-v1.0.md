# 우리편 이미지 파일명 작업 규칙 v1.0

> 작성일: 2026-04-20 | 담당: 김대웅
> 적용 범위: 우리편 홈페이지에 쓰이는 모든 이미지 파일

---

## 한 줄 요약

```
{벤더사}-{용도}-{주제}-{번호}.{확장자}
```

**영소문자 + 하이픈만.** 공백·특수문자·한글 금지.

예시:
```
torder-logo-primary-01.png
tossplace-product-androidpos-01.jpg
torder-case-bbq-01.png
```

---

## 파일명 4개 필드

### 1. 벤더사 (어느 회사/브랜드 자료?)

| 코드 | 대상 |
|---|---|
| `torder` | 티오더 |
| `tossplace` | 토스플레이스 |
| `wooripen` | 우리편 자체 제작 |

> 새 벤더사 추가 필요하면 담당자(대웅)한테 요청. 임의로 만들지 X.

### 2. 용도 (어떤 역할?)

**5개만 있다. 이 안에서 선택.**

| 코드 | 무엇을 넣나 | 예시 |
|---|---|---|
| `logo` | 브랜드 로고, 앱 아이콘, 심볼 전부 | 공식 로고, 모노 버전, 512x512 앱 아이콘 |
| `product` | 하드웨어 제품 단독 이미지 | POS, 키오스크, 프린터, 태블릿 거치대 |
| `scene` | 연출컷·배경·배너·목업·다이어그램 전부 | 매장 사용 장면, 메인 배너, 기기 합성 목업 |
| `case` | 고객 도입 사례 이미지 | BBQ 매장, 크래프트한스 등 레퍼런스 |
| `docs` | PDF, 서비스소개서, 자료집 | 채널영업팀 소개서, 파트너사 자료 |

### 3. 주제 (무엇에 관한 것?)

영소문자, 하이픈만.

| 주제 이름 | 언제 |
|---|---|
| 제품명 | `kiosk`, `pc-pos`, `androidpos`, `printer` |
| 고객사명 | `bbq`, `starbucks`, `craft-hans` |
| 로고 변형 | `primary`(기본), `mono`(단색), `reverse`(반전) |
| 범용 | `banner`, `store`, `service` |

### 4. 번호 (여러 장일 때 구분)

**2자리 숫자 필수.** `01`, `02`, `03` ...

> 1장뿐이어도 `01` 붙이기. 나중에 2장째 추가될 때 번호 꼬임 방지.

## 확장자

**원본 확장자 그대로 유지.** 절대 바꾸지 않음.

| 허용 | 용도 |
|---|---|
| `.jpg` `.jpeg` | 사진·연출컷 (용량 효율) |
| `.png` | 로고·누끼 (투명 배경) |
| `.webp` | 최신 웹 포맷 |
| `.svg` | 벡터 (로고 원본) |
| `.pdf` | `docs` 용도만 |

## Good / Bad 예시

### ✅ Good

```
torder-logo-primary-01.png
torder-logo-mono-01.png
tossplace-product-androidpos-01.jpg
tossplace-product-androidpos-02.jpg
tossplace-scene-store-01.jpg

```

### ❌ Bad (이런 거 올리면 반려됨)

| 잘못된 파일명 | 문제점 |
|---|---|
| `t'order_Brand_Logo_1.png` | 특수문자 · 대문자 · 언더스코어 |
| `android_pos_1 (1).jpg` | 괄호 · 공백 · 벤더 누락 |
| `main-design-bnr1.jpg` | 벤더 없음, 용도 불명확 |
| `티오더_로고.png` | 한글 금지 (영문만) |
| `Torder-Logo-Primary.png` | 대문자 금지 |
| `torder-logo-primary.png` | 번호 `01` 누락 |

## 업로드 위치

### 구글드라이브 폴더 구조

```
📁 WOORIPEN-파트너이미지자료/
├── 📄 README.md
├── 📁 _inbox/          ← 벤더 불명/분류 헷갈릴 때 임시
├── 📁 torder/          ← 티오더 이미지 전부
├── 📁 tossplace/       ← 토스플레이스 이미지 전부
└── 📁 wooripen/        ← 우리편 자체 제작 이미지
```

**용도별 하위폴더는 없음.** 파일명에 이미 다 들어있으니까 벤더 폴더에 그냥 다 때려넣어도 됨.

### 업로드 순서

```
1. 원본 받음 → 파일명 규칙대로 리네임
2. 해당 벤더 폴더로 업로드
3. 헷갈리면 _inbox/ 에 올리고 담당자 확인
```

## 자주 헷갈리는 케이스

**Q1. 로고인지 아이콘인지 애매한데?**
→ 전부 `logo`로 통일. 앱 아이콘도 로고의 한 형태. 고민 X.

**Q2. 목업인지 연출컷인지 애매한데?**
→ 전부 `scene`으로 통일. 실사/일러스트/합성/배너/배경 전부 `scene`.

**Q3. 같은 제품을 여러 각도에서 찍은 게 10장?**
→ 번호만 늘려: `tossplace-product-kiosk-01.jpg` ~ `tossplace-product-kiosk-10.jpg`

**Q4. 도입사례 고객사가 여러 업종인데 업종으로 분류 필요?**
→ 업종 구분 안 함. 고객사명 그대로: `torder-case-bbq-01.png`, `torder-case-starbucks-01.png`

**Q5. 원본 파일명에 연도나 버전이 있는데?**
→ 파일명엔 연도·버전 안 넣음. 교체할 땐 기존 파일을 `_archive/` 로 이동 후 신버전을 같은 이름으로 업로드.

**Q6. 새로운 용도가 필요한 것 같은데?**
→ 5개 외 용도 임의 추가 X. 담당자에게 요청.

업로드 직전에 아래 7개 다 `[x]` 되면 OK.

- [ ] 벤더사 코드가 허용 목록(`torder` / `tossplace` / `wooripen`) 안에 있나?
- [ ] 용도 코드가 5개(`logo` / `product` / `scene` / `case` / `docs`) 안에 있나?

- [ ] 번호가 2자리 숫자인가? (`01` O, `1` X)
- [ ] 대문자 · 공백 · 특수문자 · 한글 없나?
