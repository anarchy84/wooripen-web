## 1. CRMPro 연동 — API 키 및 필드 정책 (#2, P0)

상담 신청이 CRM으로 전송되도록 코드는 완성했습니다. 아래 3가지가 필요합니다.

### (1) API 키
- `crmpro.kr` 발급 **X-API-Key** 값
- ⚠️ **이 문서나 메신저에 적지 마시고**, Vercel 환경변수에 직접 등록해 주세요
  - Vercel → wooripen-web 프로젝트 → Settings → Environment Variables
  - 변수명: `CRM_PRO_API_KEY` (Production 환경)
- 등록 전까지는 CRM 전송만 자동으로 건너뛰고, 상담 접수·DB 저장은 정상 동작합니다

### (2) `etc1` (업종) 처리 방침
CRM 필수 필드인데 **폼에서 수집하지 않습니다.** 7개 상담 폼 중 `/recommend` 하나만 업종 입력란이 있습니다.

현재는 업종이 없으면 **관심 상품 카테고리**(예: "결제단말기", "인터넷")를 대신 넣도록 해두었습니다.

- [ ] 이대로 진행
- [ ] 빈값('미입력')으로 전송
- [ ] 폼에 업종 선택 항목 추가 (→ 추가 개발 필요, 폼 이탈률 영향 검토 필요)

### (3) `etc3` (통화가능시간) 처리 방침
역시 CRM 필수인데 **폼 어디에도 없습니다.** 현재 `'미정'` 고정값으로 보냅니다.

- [ ] 이대로 진행
- [ ] 다른 고정값 사용 (예: '시간무관') → 값 지정 필요
- [ ] 폼에 항목 추가 (→ 추가 개발 필요)

### (4) 테스트 그룹
운영 그룹(`116.인바운드_우리편`)에 가짜 리드가 섞이지 않도록, **테스트용 group_no**가 있으면 알려주세요. 1건 전송해 필드 매핑을 확인한 뒤 116으로 전환하겠습니다. 없으면 116으로 바로 1건 테스트하고 CRM에서 삭제하는 방식으로 진행합니다.

## 2. 카카오톡 채널 URL (#4, P0)

기존 링크 `https://pf.kakao.com/_우리편` 는 **작동하지 않습니다.** 카카오 채널 ID는 영문·숫자만 사용 가능한데 한글이 들어가 있었고, 카카오 API로 조회한 결과 **해당 채널이 존재하지 않습니다**(404).

즉 지금까지 카톡 상담 경로가 죽어 있었습니다.

**필요한 것**: 실제 카카오톡 채널 주소
- 형태 예시: `https://pf.kakao.com/_abcdEF` 또는 채널 검색용 ID `@우리편`
- 카카오 비즈니스 → 채널 관리 → 채널 정보에서 확인 가능

**채널이 아직 없다면**: 개설이 선행되어야 합니다. 개설 여부를 알려주세요.

**입력 방법**: 어드민 → 사이트 설정 → 카카오톡 채널 (개발자 없이 즉시 반영되도록 바꿔두었습니다)

> 현재 상태: 주소가 없거나 형식이 잘못되면 **버튼을 아예 숨기도록** 처리했습니다. 죽은 링크를 클릭하는 것보다 낫다고 판단했습니다.
