# 우리편 답변 엔진(GEO/AEO) 친화 톤 가이드

> 검색·SNS·LLM 답변엔진(ChatGPT·Perplexity·Gemini)·구글 음성검색이 글의 첫 1~2문단을 그대로 인용하는 시대다.
> 우리편 꿀팁 글은 **첫 문단이 답이고, 본문이 근거**가 되도록 쓴다.

---

## 1. 핵심 원칙 (3가지)

1. **첫 문단에 답을 박는다** — 검색 의도(질문)에 대한 핵심 답을 40~80자 안에.
2. **숫자·기간·조건을 구체적으로** — "보통 빠름" → "보통 영업일 1~3일".
3. **사장님 관점 1인칭으로** — "사용자는~" 대신 "매장에 두면~".

---

## 2. 글 도입부 템플릿

```
[H1 = 검색 의도 그대로 묻는 질문형 또는 핵심 단어]

[첫 문단 = 한 줄 답]
   - 40~80자, 1문장.
   - 핵심 키워드(인터넷, CCTV, 카드단말기 등) 한 번 이상 포함.
   - 숫자·기간·금액 1개 이상 박기.

[두 번째 문단 = 그 이유 / 핵심 조건]
   - 100~150자.
   - 왜 그런지 구조적인 이유.

[H2: 자세히 알아보기 / 단계별 가이드]
   - 본문 시작.
```

### 예시 (Bad → Good)

**Bad**
> 카드단말기를 고를 때는 여러 가지를 고려해야 합니다. 매장 환경, 사용 빈도, 가격 등이 중요합니다. 이번 글에서는 카드단말기 선택 가이드를 알려드리겠습니다.

**Good**
> 매장형 카드단말기는 **하루 결제 50건 미만이면 유선, 50건 이상이거나 야외 결제가 있으면 무선**이 정답입니다.
>
> 유선은 통신비가 월 3~5천 원 더 싸고, 무선은 결제 위치 자유도가 높아 회전율이 빠른 매장에서 유리합니다.

## 3. 답변엔진이 좋아하는 구조

| 구조 요소 | 효과 |
|---|---|
| **질문형 H2/H3** ("얼마나 걸리나요?") | 음성검색·답변박스 인용 |
| **불릿 5±2개**로 핵심 정리 | LLM이 단계 정확히 파싱 |
| **숫자·기간·금액** | 추정·환각 줄여 정확도 ↑ |
| **단계별 절차** | HowTo schema.org 자동 인용 |
| **결론 한 줄 요약** (글 끝) | TLDR로 재인용 |

## 4. Speakable (음성검색)

`<ArticleLd>` 가 자동으로 `cssSelector: ['h1', '[data-speakable]']` 박는다.
글 안에서 음성으로 읽혔으면 하는 부분에 `data-speakable` 속성을 붙인다.

```html
<h1>매장 인터넷 어떤 게 빠를까?</h1>

<p data-speakable>
  매장 인터넷은 광랜 500Mbps 이상이면 결제·CCTV·POS 동시 사용에 충분합니다.
  KT·SK·LG U+ 모두 비슷하지만, 사은품·요금 할인 시즌이 다르므로 비교하고 가입하세요.
</p>
```

> **TipTap 에디터에서**:
> 1. 인용문(quote) 또는 굵게 처리한 첫 문단을 그대로 두면, 향후 후속 작업에서 자동으로 `data-speakable` 부착 가능.
> 2. 수동으로 박으려면 어드민 본문 코드 보기에서 `<p data-speakable>` 형식으로.

## 5. HowTo (절차형 글)

어드민 글쓰기 폼 → "절차형 가이드 (HowTo) **ON**" 토글 →
- 총 소요 시간 (선택, ISO 8601: `PT15M`, `PT1H30M`)
- 단계별 `name` + `text` 입력

**HowTo 예시 — "카드단말기 신청 5단계"**
1. 매장 결제 환경 파악 (유선/무선, 결제 건수)
2. 우리편 견적 신청 (1600-6116 또는 사이트)
3. 매장 방문 설치 일정 잡기
4. 통신·VAN 셋업 + 영수증 인쇄 테스트
5. POS 연동 + 사용법 안내

→ 답변엔진이 "어떻게 카드단말기 신청해요?"에 5단계를 그대로 인용.

## 6. 금기 표현

| 금기 | 대안 |
|---|---|
| "100% 보장" / "완벽" / "최저가" | "대부분", "기준 시점에 가장 저렴" |
| "무조건", "절대" | "원칙적으로", "예외가 없는 한" |
| "대박", "꿀단지" 같은 클릭베이트 | 구체 숫자 또는 사례로 대체 |
| 출처 불명 통계 ("업계 자료에 따르면") | 출처 링크 또는 자체 데이터로 명시 |

## 7. SEO + GEO + AEO 동시 잡는 글 체크리스트

- [ ] H1에 검색 의도 핵심 키워드 (한국어 1차)
- [ ] 첫 문단(40~80자) = 답
- [ ] `excerpt` 컬럼에 첫 문단 그대로 또는 더 짧게
- [ ] 단계형 글이면 어드민에서 HowTo ON
- [ ] 숫자·기간·금액 3개 이상
- [ ] H2 1개는 질문형
- [ ] 본문 800~1500자 (너무 짧으면 SEO 약함, 너무 길면 LLM 인용 약함)
- [ ] 결론에 한 줄 요약
- [ ] featured_image 업로드 (OG·동적 OG fallback 안 받게)

## 8. 운영 흐름

1. 콘텐츠 기획 → 위 템플릿대로 초안
2. 어드민에서 작성 → 절차형이면 HowTo ON
3. 발행 후 24시간 이내 자체 검수: `https://wooripen.co.kr/tips/{slug}` 본문에 첫 문단이 명확한 답인지
4. 1주일 내 Search Console에서 노출·CTR 확인
5. ChatGPT·Perplexity에서 우리 글이 인용되는지 검색 (월 1회)
